# Nmap Scanning Lab

## Overview
This repository documents my practical use of Nmap for network discovery, port scanning, service enumeration, operating system detection, and basic vulnerability assessment.

## Tools Used
- Kali Linux
- Nmap
- Linux Terminal

## Objectives
- Host Discovery
- TCP Port Scanning
- UDP Scanning
- Service Enumeration
- Version Detection
- OS Detection
- NSE Script Scanning

## Skills Demonstrated
- Network Reconnaissance
- Information Gathering
- Enumeration
- Security Assessment

## Learning Outcome
This project demonstrates my ability to use Nmap effectively during the reconnaissance phase of a penetration test.
